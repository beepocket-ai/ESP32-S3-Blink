# ESP32-S3 WS2812 多效果灯

基于 ESP-IDF 的 ESP32-S3 示例工程：驱动板载 WS2812 灯珠（GPIO48）演示 19 种灯效，
按板载 **BOOT** 键或外接 **红色按键模块** 切换到下一个效果，同时通过串口打印当前效果。

## 目录结构

```
ESP32-2812/
├── CMakeLists.txt          # 工程入口
├── sdkconfig                # 本机生成的配置
└── main/
    ├── CMakeLists.txt      # 组件注册
    └── main.c              # 全部代码：RMT 驱动 + 效果表 + 按键
```

## 硬件

- ESP32-S3 开发板（已在 ESP32-S3 QFN56、8MB PSRAM、16MB flash 的板子上验证）
- 板载 WS2812 彩灯，数据线为 **GPIO48**（无需外接）
- 可选：外接按键模块，三脚 `VCC / OUT / GND`

### 外接红色按键模块接线

| 按键模块 | ESP32-S3 |
|---|---|
| VCC | **3V3**（不要接 5V，否则 OUT 会输出 5V 打坏 GPIO） |
| GND | GND |
| OUT | GPIO10 |

模块自带板载上拉，OUT 空闲为高、按下为低（低电平有效）。代码中同时启用了内部上拉，可并联工作。

## 编译与烧录

在 ESP-IDF 环境下（示例使用 v5.5.6）：

```powershell
idf.py set-target esp32s3
idf.py build
idf.py -p COM10 flash monitor
```

串口波特率默认 115200，`Ctrl+]` 退出 monitor。

## 代码要点

- **时序**：使用 RMT 发送通道，分辨率 10MHz（1 tick = 0.1µs），字节编码器输出
  `0 码 = 高 0.3µs / 低 0.9µs`、`1 码 = 高 0.9µs / 低 0.3µs`，GRB 顺序、MSB 优先。
- **复位**：发送完成后保持低电平 300µs。
- **帧循环**：每 10ms 计算并发送一帧。
- **效果实现**：全部为"时间驱动 + 无状态"函数 `void fx(uint32_t t_ms, uint8_t *r, uint8_t *g, uint8_t *b)`，
  根据当前时间直接算出颜色，切换效果不需要清理状态。随机效果使用无状态哈希函数。
- **按键**：两个引脚各自独立记录状态，30ms 消抖；上电后先等 100ms 建立电平基线，避免上电误触发。
- **新增效果**：在 `main.c` 里写一个 `fx_xxx` 函数，然后加入 `s_effects[]` 数组即可。

## 可调参数

| 参数 | 位置 | 说明 |
|---|---|---|
| `WS2812_GPIO` | 宏定义 | 数据引脚，默认 48 |
| `WS2812_LED_COUNT` | 宏定义 | 灯珠数量，默认 1（板载） |
| `WS2812_RESOLUTION_HZ` | 宏定义 | RMT 发送通道分辨率，默认 10MHz |
| `BTN_GPIO_BOOT` | 宏定义 | 板载 BOOT 键，默认 0 |
| `BTN_GPIO_EXT` | 宏定义 | 外接按键，默认 10 |
| `BTN_DEBOUNCE_MS` | 宏定义 | 按键消抖时间，默认 30ms |
| `MAX_LEVEL` | 宏定义 | 最亮值，默认 80（单颗灯珠不建议开满 255） |
| `FRAME_MS` | 宏定义 | 帧间隔，默认 10ms |
| 番茄钟时长 | `fx_pomodoro` | `work_ms` / `break_ms` |

## 常见问题排查

**灯珠不亮**

1. 先确认数据线接到灯带的 **DIN**（不是 DOUT），且箭头方向正确。
2. 外接 5V 灯带时，3.3V 的 GPIO 信号低于 WS2812B 的输入门限（0.7 × VDD ≈ 3.5V），
   会出现"接线正确但全黑"。解决办法：VDD 与 5V 之间串一只 1N4007 / 1N5819 降压到约 4.3V，
   或用 74AHCT125 做 3.3V → 5V 电平转换。
3. 供电不足会整体不亮：单颗 0.3W，多颗时建议外部 5V 电源并共地，电源端并 1000µF 电容。

**按 BOOT 没有反应**

- 上电瞬间按住 BOOT 会进入下载模式，程序不运行；日常请在上电后再按。
- 少数第三方板的 BOOT 键不在 GPIO0，可用串口日志或万用表（通断档一端接 GPIO0 排针、另一端接 GND）确认。

**上电自动跳到第 2 个效果**

- 按键模块上电电平未稳定导致误判。代码已在上电后等待 100ms 建立基线；
  若个别模块更慢，可把该延时加大到 300ms。

**启动循环报 `XMC flash startup fail` 并重启**

这批 16MB XMC flash（`Manufacturer 0x20 / Device 0x7018`）的型号 ID 不在 ESP-IDF 的严格匹配列表里，
bootloader 走完 DPD/UDPD 唤醒流程后仍判定失败，导致无限重启。本机已修改共享 IDF 源码：

`C:\esp\v5.5.6\esp-idf\components\bootloader_support\bootloader_flash\src\bootloader_flash.c`

把启动流程的事后校验放宽为"厂商 ID 为 XMC 即通过"。该修改对本机所有工程生效，回滚方式：

```powershell
git -C C:\esp\v5.5.6\esp-idf checkout components/bootloader_support/bootloader_flash/src/bootloader_flash.c
```

**flash 容量**

芯片实际为 16MB，`sdkconfig` 中仍为 2MB。需要更多空间时在 `idf.py menuconfig` 中把
Flash size 改为 16MB 并重新配置分区表。
